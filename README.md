# Gym Form Website

A simple and modern single-page gym registration website created using **HTML5** and **CSS3**. This project is designed for beginners to practice frontend web development and form designing.

## Features

 Single-page gym website layout
 Navigation bar with menu links
 Gym branding and logo section
 User registration form
 Stylish buttons and hover effects
 Background image design
 Clean and beginner-friendly code

Technologies Used

HTML5
CSS3

Project Structure


│── index.html
│── gympic.jpg
│── gymlogo.jpg


## How to Use

1. Download or clone the repository
2. Keep all files in the same folder
3. Open `index.html` in any browser
